## Required verification on a networked machine
```bash
cd frontend
npm install --package-lock-only
npm ci
npm run build

cd ..
python scripts/static_checks.py
cp .env.example .env  # set a strong POSTGRES_PASSWORD
docker compose config -q
docker compose -f docker-compose.yml -f docker-compose.dev.yml config -q
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```
Then run backend integration tests with a dedicated disposable PostgreSQL database and `TEST_DATABASE_URL`.
